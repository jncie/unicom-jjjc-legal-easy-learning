# unicom-jjjc-legal-easy-learning
Unicom JJJC Legal Easy Learning - Tampermonkey automation script for China Unicom's internal learning platforms (aiportal.chinaunicom.cn &amp; lawplatform.chinaunicom.cn). Automates daily credit tasks including auto like, auto collect, cross-page navigation, media blocking, persistent timer, cross-tab state sync — making learning tasks effortless.
